# PyQt6 Media Player

## 📌 Описание проекта

Данный проект представляет собой настольное приложение — **медиаплеер с поддержкой аудио и видео файлов**, разработанное с использованием библиотеки **PyQt6**.
Приложение позволяет воспроизводить мультимедийные файлы, управлять плейлистами и сохранять данные в базе данных SQLite.

Проект разработан в рамках учебной дисциплины и демонстрирует работу с графическим интерфейсом, мультимедиа, базами данных и событийной моделью Qt.

---

## 🎯 Цель работы

Разработать PyQt-приложение с графическим интерфейсом, созданным в **Qt Designer**, реализующее:

* работу с мультимедиа,
* взаимодействие с базой данных,
* обработку событий клавиатуры и мыши,
* модульную архитектуру и объектно-ориентированный подход.

## 🧩 Функциональные возможности

* загрузка аудио и видео файлов;
* воспроизведение, пауза, остановка;
* регулировка громкости и позиции воспроизведения;
* создание и управление плейлистами;
* **один трек может находиться одновременно в нескольких плейлистах**;
* **единая база «Все треки»** — все добавленные песни всегда доступны;
* **удаление трека из плейлиста не удаляет его из базы**;
* сохранение треков и плейлистов в базе данных;
* контекстное меню (правый клик) для управления треками;
* горячие клавиши управления;
* поддержка стандартных диалогов Qt.

## 🪟 Интерфейс приложения

Приложение состоит из нескольких форм:

* главное окно медиаплеера;
* диалоговое окно управления плейлистами.

Все формы созданы с помощью **Qt Designer** и подключаются через `.ui` файлы.

## 🗄 Работа с базой данных

В проекте используется база данных SQLite со следующими таблицами:

### Таблица `playlists`

* `id` — идентификатор плейлиста
* `name` — название плейлиста

### Таблица `tracks`

* `id` — идентификатор трека
* `title` — название
* `file_path` — путь к файлу (уникальный)
* `duration` — длительность

### Таблица `track_playlist`

Связь «многие-ко-многим» между треками и плейлистами:

* `track_id` — идентификатор трека
* `playlist_id` — идентификатор плейлиста

Благодаря этой таблице **один трек может присутствовать в нескольких плейлистах одновременно**, а удаление связи не удаляет сам трек из базы.

Реализованы операции добавления, чтения, изменения и удаления данных (CRUD).

## ⌨ Управление

| Клавиша | Действие |
|---------|----------|
| **Space** | Воспроизведение / пауза |
| **Ctrl + O** | Открыть файл |
| **Ctrl + →** | Следующий трек |
| **Ctrl + ←** | Предыдущий трек |
| **Delete** | Удалить трек |
| **Двойной клик мышью** | Воспроизведение трека |
| **Правый клик** | Контекстное меню (добавить в плейлист / удалить из плейлиста) |
